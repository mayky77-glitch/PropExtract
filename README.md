# PropExtract

PropExtract — локальная программа для пакетного переноса реквизитов из PDF-разрешений на строительство в реестр Excel. Она распознаёт сканы, группирует версии одного разрешения, переносит подтверждённые значения и сохраняет формулы, стили и встроенную цветовую индикацию сроков.

Все документы обрабатываются на компьютере пользователя. Сервер доступен только по адресу `127.0.0.1` и не отправляет файлы во внешние сервисы.

## Возможности

- загрузка большого набора PDF через путь к папке, включая вложенные папки;
- системные окна выбора папки PDF и целевого Excel без ручного ввода пути;
- OCR сканов на русском и английском языках; одинаковые модели `rus/eng` хранятся в репозитории и проверяются по SHA-256;
- выбор актуальной версии документа по номеру РнС и дате;
- заполнение доступных полей реестра и обновление ссылки на исходный PDF;
- отдельная отметка в админке для PDF, которые уже внесены в реестр и полностью совпадают по всем переносимым полям Excel;
- предложения по каждому занятому отличающемуся полю: оператор видит строку, РНС и исходный PDF и отдельно подтверждает перенос;
- проверка формул, стилей, ссылок и правил цветовой индикации перед публикацией;
- автоматическая резервная копия целевого Excel перед заменой;
- JSON-отчёт рядом с обновлённым реестром;
- прогресс обработки и имя текущего документа;
- продолжение пакетной обработки, если отдельный PDF повреждён или не читается; причина сохраняется в отчёте;
- номера обработанных и отдельно добавленных строк Excel в результате запуска;
- столбец `AA — Статус переноса` с конкретной причиной для неподтверждённых или конфликтующих полей; при полном переносе ячейка пустая;
- светлая и тёмная темы, автоматический выбор по настройкам системы;
- отдельная страница с инструкцией и проверка готовности OCR-компонентов.

## Как работает перенос

1. Программа проверяет папку PDF и целевой файл `.xlsx`.
2. Для PDF с текстовым слоем используется `pdftotext`; сканы рендерятся через Poppler и распознаются Tesseract (`rus+eng`).
3. Документы с одинаковым номером РнС объединяются по полям: более поздний подтверждённый срок и дата изменения выбираются независимо от порядка файлов, а спорное недатированное значение остаётся на проверку.
4. Изменения записываются во временный Excel. Рабочий файл в этот момент не меняется.
5. Временный файл повторно открывается и проверяется. Затем создаётся резервная копия рабочего Excel.
6. Только после успешных проверок временный файл атомарно занимает место целевого реестра.

Если обработка завершается ошибкой до последнего шага, целевой Excel остаётся прежним. Если повторный запуск нашёл, что все переносимые значения уже совпадают, это **no-op**: Excel не перезаписывается, его байты и время изменения сохраняются, а новая резервная копия не создаётся.
Если ни в одном PDF не найден номер РНС, программа завершает задачу без публикации Excel. Расширения `.pdf` и `.PDF` обрабатываются одинаково.

## Установка в Windows

Поддерживаются 64-битные Windows 10/11. Windows 11 ARM64 поддерживается через встроенную эмуляцию x64 и обязательно проверяется перед первым запуском. Windows 10 ARM64 не поддерживается: для закреплённого x64 OCR runtime требуется эмуляция Windows 11. 32-битная Windows не поддерживается текущими версиями Tesseract и Poppler.

Откройте командную строку в папке проекта и выполните одну команду:

```bat
install_windows.cmd
```

Можно также дважды нажать `install_windows.cmd` в Проводнике. Скрипт развернёт внутри проекта portable Python 3.12.10, Tesseract 5.5.3 и Poppler 25.07, проверит OCR и запустит PropExtract.

`WinGet`, Microsoft Store, системный Python, сеть и права администратора не нужны. Окно UAC появляться не должно. Все Windows-компоненты и Python-пакеты уже находятся в папке `packages/`. Путь к распакованному GitHub-архиву может содержать кириллицу, пробелы, `&` и скобки: все встроенные архивы распаковываются Unicode-safe средствами PowerShell/.NET. До распаковки установщик проверяет рассчитанные пути runtime (длину, границы и отсутствие ссылок внутри `.runtime`), возможность записи и свободное место; параллельная установка той же копии проекта отклоняется локальной mutex-блокировкой. Runtime собирается во временной папке и до первого запуска сверяется с `windows-runtime.lock.json`. При ошибке публикации восстанавливается предыдущая runtime-копия, а старые `.invalid.*` копии удаляются только после проверки новой. При каждом последующем запуске оба дерева — Python и OCR — проверяются заново. Повреждённый, подменённый или перенаправленный через junction файл не используется.

Если защитное ПО удалило файл из `.runtime`, просто повторно запустите `install_windows.cmd`: установщик обнаружит повреждение и восстановит Python/OCR из проверенных локальных архивов. Если в карантин попал сам архив из `packages/`, установщик остановится до запуска кода и сохранит журнал `install-windows.log`. Не отключайте антивирус: проверьте его журнал и правила организации, затем заново скачайте проект из GitHub либо согласуйте файл с администратором.

После установки не нужно снова запускать установщик:

- дважды нажмите **`Запустить PropExtract.cmd`**, чтобы открыть программу;
- нажмите **«Остановить»** в правом верхнем углу сайта либо дважды нажмите **`Остановить PropExtract.cmd`**, чтобы завершить локальный сервер.

Технические файлы `start_windows.cmd` и `stop_windows.cmd` выполняют те же действия из командной строки. Запуск сверяет идентификатор именно этой папки проекта: повторный запуск той же копии только открывает уже работающий экземпляр, а другой процесс на порту не считается PropExtract. Остановка ждёт завершения своего экземпляра и после неё можно сразу снова запустить программу.

При ошибке обработки интерфейс показывает этап и имя PDF без внутренних путей и диагностических кодов. Полный технический журнал сохраняется в `propextract-error.log` рядом с программой; исходный Excel при этом не изменяется. Подсказка закрыть Excel выводится только при реальном отказе Windows в доступе к файлу.
Краткие блокировки файла со стороны OneDrive, антивируса или индексатора повторяются автоматически не более 20 раз и до 15 секунд; постоянная блокировка завершается понятной ошибкой.

Для диагностического запуска без открытия сервера:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install_windows.ps1 -NoStart
```

Установщик намеренно не выполняет сетевых запросов. Если локальный пакет удалён или повреждён, он остановится до запуска кода и попросит заново скачать проект.

## Установка в Linux

Для Ubuntu/Debian и Fedora одна команда:

```bash
./install_linux.sh
```

Если право запуска потерялось после распаковки: `chmod +x install_linux.sh && ./install_linux.sh`. Скрипт сам выберет `apt-get` или `dnf`, установит пакеты, создаст `.venv`, проверит OCR и запустит PropExtract.

Повторный запуск: `./start_linux.sh`.

## Работа в интерфейсе

1. Закройте целевой реестр в Excel или LibreOffice.
2. Нажмите **Выбрать** и укажите папку с PDF в системном окне. Если окно не видно, проверьте панель задач Windows. Путь из команды «Копировать как путь» можно вставить вручную вместе с кавычками — программа удалит их сама.
3. Нажмите **Выбрать** у поля Excel и укажите целевой `.xlsx`.
4. Нажмите **Перенести данные** и дождитесь статуса **Готово**.
5. Результаты сгруппированы по состоянию строки. В карточке видно номер строки Excel, краткое описание, исходный PDF и, если значения различаются, сравнение **«В таблице» → «В документе»**. Нажмите **«Перенести в таблицу»** только после проверки: для каждого такого действия создаётся новая проверенная резервная копия, а Excel заменяется атомарно. После работы нажмите **Остановить**.

Служебные столбцы `Y` и `Z` исходного реестра заняты формулами, поэтому статус записывается в первый свободный столбец `AA`. Импорт распознаёт номера РНС форматов `38-…`, компактный `38…` и `RU-…`, включая разделители и частые OCR-варианты префикса. Единственный номер в ограниченном поле формы `Номер разрешения на строительство` считается основным, даже если OCR нашёл в другом месте ещё один справочный номер; два номера в самом поле остаются неоднозначными. Для похожего на разрешение скана без найденного номера программа один раз повторяет только распознавание личности документа при 400 DPI с ограничением до 10 страниц; неоднозначный номер не угадывается. В ячейке реестра номер может быть оформлен как `№ … от …` с датами изменений: перенос сравнивает только единственный найденный номер и сохраняет исходное оформление ячейки. Несколько совпадающих строк или несколько номеров в ячейке требуют ручной проверки; данные в них не перезаписываются. Изменения и продления с явным номером обновляют только ровно одну найденную строку реестра и никогда не создают новую; при отсутствии или неоднозначности строки они остаются в отчёте для проверки. Более поздний явный срок из связанного изменения/продления заменяет старый; равная, более ранняя или нераспознаваемая дата не может ухудшить данные, а ссылка ведёт к документу-источнику актуального поля. Если связанные изменения содержат разные значения другого поля, программа не выбирает одно по порядку файлов: строка остаётся на проверку с русским пояснением. Запись только с номером, без подтверждённых полей, также не меняет реестр. Безопасные различия регистра, пробелов, `ё/е`, Unicode, видов кавычек и тире не считаются конфликтом; в названии объекта можно отбросить только доказанное стандартное вводное описание перед тем же явным `Этап N`, но остальные слова до и после этапа остаются значимыми. Базовый контракт нормализации адаптирован из модуля `report_processor.training_data.normalization` проекта Document Optimizer.

Резервные копии складываются в папку `Резервные копии PropExtract` рядом с реестром. Встроенная страница **Инструкция** содержит краткую памятку оператору.

## Консольный режим

Режим создания отдельного файла, без замены исходного Excel:

```bash
python -m rns_import_server.app process \
  --pdf-dir "/полный/путь/к/pdf" \
  --xlsx "/полный/путь/к/реестру.xlsx" \
  --output "/полный/путь/к/результату.xlsx"
```

Запуск сервера вручную:

```bash
python -m rns_import_server.app serve --host 127.0.0.1 --port 8775
```

## Безопасность данных

- сервер намеренно запрещает внешний сетевой адрес;
- пути-символические ссылки не принимаются для входных документов;
- рабочие PDF не изменяются;
- Excel публикуется через временный файл только после проверок;
- новая строка получает стили и формулы предыдущей строки; стили всех остальных строк проверяются без послаблений;
- при полном совпадении существующей строки её значения, стили, ссылка и статус не меняются; Excel пересчитывает родные цветовые маркеры сроков при открытии;
- перед заменой проверяется хэш исходного Excel и резервной копии; отдельное подтверждение также проверяет строку, источник и актуальность Excel;
- репозиторий исключает PDF, XLSX, отчёты, локальные среды и резервные копии через `.gitignore`;
- Windows-артефакты версионированы и проверяются до выполнения или распаковки;
- Python-зависимости устанавливаются только из локальных wheel-файлов с обязательными SHA-256;
- проект не содержит ключей API, паролей или телеметрии.

## Одинаковый OCR в Windows и Linux

Файлы `rns_import_server/tessdata/rus.traineddata` и `eng.traineddata` входят в Git-репозиторий. PropExtract принудительно передаёт Tesseract путь к этим моделям, а не к языковым файлам операционной системы. Перед запуском сверяются хэши обеих моделей. Модели из [официального репозитория Tesseract](https://github.com/tesseract-ocr/tessdata), лицензия Apache-2.0.

В Windows portable Python 3.12.10, движок Tesseract 5.5.3, его DLL, Poppler 25.07 и app-local Visual C++ Runtime закреплены внутри проекта и не смешиваются с системными версиями. Системное окно выбора файла/папки открывается через встроенный Windows Forms, поэтому отдельный Tkinter не нужен. В Linux используются пакеты дистрибутива, но те же языковые модели. Установщики проверяют все компоненты командой `python -m rns_import_server.runtime`. PDF без текстового слоя рендерятся и OCR-обрабатываются пакетами по две страницы; это ограничивает одновременные временные изображения и не меняет порядок страниц. Полное побайтовое равенство OCR между разными ОС не гарантируется, но Windows-компьютеры используют один и тот же движок и модели.

## Разработка и тесты

```bash
python -m pip install -r requirements-dev.txt
python -m pytest tests/test_admin_server.py
```

Основной код находится в `rns_import_server/`: `app.py` управляет импортом, `server.py` — локальными задачами и HTTP, `ocr.py` — OCR, `rns_adapter.py` — правила извлечения, `workbook.py` — безопасная запись Excel.
