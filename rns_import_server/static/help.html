Инструкция оператора

От папки со сканами
до готового реестра.

Обычный запуск состоит из четырёх шагов. Excel лучше закрыть перед началом обработки.

01

Подготовьте PDF

Сложите разрешения в одну папку. Вложенные папки допустимы. Исходные PDF не изменяются.

02

Закройте Excel

Выберите рабочий .xlsx. Если он открыт в Excel, Windows может запретить замену файла.

03

Выберите файлы

Нажмите «Выбрать» рядом с каждым полем: откроется обычное системное окно для папки PDF и файла Excel.

04

Запустите перенос

Дождитесь отметки «Готово». После работы нажмите «Остановить»; в следующий раз откройте «Запустить PropExtract.cmd».

Что меняется

Только подтверждённые значения

Программа группирует версии одного разрешения, выбирает актуальный документ и заполняет доступные поля. Существующий отличающийся срок не перезаписывается — он попадает в отчёт как конфликт. Ссылка на документ обновляется.

Если запись уже есть и все переносимые данные PDF совпадают с Excel, админка покажет имя такого PDF. Строка, её ссылка и статус не меняются; при открытии Excel пересчитаются только родные цветовые маркеры сроков.

Что сохраняется

Формулы, стили и цветовые сроки

Перед публикацией файл повторно открывается и проверяется. Встроенные правила цветовой индикации сроков переносятся без изменений. Причины непереноса записываются в столбец «Статус переноса»; при полном переносе ячейка пустая.

Как отменить

Вернитесь к резервной копии

До замены реестра создаётся папка «Резервные копии PropExtract». Скопируйте нужную версию обратно на место рабочего файла.

Ручная сверка

Исправить данные

Кнопка доступна только для строк, добавленных текущим запуском, или строк, требующих проверки. Можно изменить только деловые поля: номер РНС, ссылка на документ, формулы Y:Z и статус AA защищены. При сохранении создаётся проверенная резервная копия.

Приватность

Обработка остаётся локальной

OCR и работа с Excel выполняются на вашем компьютере. Сервер слушает только локальный адрес и не отправляет документы во внешние сервисы.

Если что-то не работает

Быстрая проверка

OCR-компоненты не готовы
Установите Tesseract с языками rus и eng, а также Poppler. Команды должны быть доступны в PATH.
Файл Excel не заменён
Закройте его в Excel и повторите запуск. До успешного завершения рабочий файл остаётся прежним.
Окно выбора не видно
Проверьте панель задач Windows: окно открывается поверх браузера с названием PropExtract. Если окно не появилось, путь можно вставить вручную — кавычки из «Копировать как путь» удаляются автоматически.
PDF не найден
В первом поле нужна папка, а не отдельный PDF. Ошибка теперь показывает, какой именно путь не найден.
